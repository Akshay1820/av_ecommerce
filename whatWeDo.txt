    Problems with Monolithic Architecture
        Difficult to Implement Changes:- If we want to change one module, it may affect other modules as well

        Lack of Scalability:- If a specific module is large amount of traffic, we cant scale a specific module,like increasing instance, increasing RAM

        Long-term Commitment to a Single Technology Stack

        Application Complexity and its Effect on Development and Deployment:- As application grows it slows down the development, increase chances of bugs

        Slowing Down of IDEs

        Increase Application Start time

        Large Project Size


    Principle of Microservices:-

        Single Responsibility:- Each microservices have one job.

        Independence:- Change in one service not affect other services. They operate independently

        Decentralization

        Failure Isolation:- If one service fail, the rest of application should continue to function as it is.

        Continuous Delivery/Deployment:- Releases can be happen more frequently.


    So now we moving our monolithic application to microservice architecture
